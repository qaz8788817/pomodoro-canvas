# pomodoro-canvas
一個任務倒數計時的時鐘

## 使用方法
```/todo [task] [mins]```：對```[task]```開始倒數計時。
```/p```：倒數暫停。
```/r```：繼續計時。
```/reset```：重置時間。

* 開始計時後，會縮小視窗並永遠固定在螢幕前，不會被其他應用程式蓋住。
* 在過程中也可以直接輸入以上指令操控倒數時鐘。
* 點擊小時鐘會回復到原本的大小。
